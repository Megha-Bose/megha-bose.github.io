Space Complexity - When Memory, Not Time, Is the Bottleneck

Aug 2021
5 min read

Helpful context:

  • P, NP, and the Hardest Problems - The Question That Keeps Theorists Up at Night
  • Turing Machines - The Minimal Model of Everything a Computer Can Do

Merge sort and heap sort both take $O(n \log n)$ time. But merge sort needs $O(n)$ extra memory, while heap sort needs $O(1)$: one could run on a tiny embedded chip and the other couldn’t. Time complexity asks how long; space complexity asks how much memory. The two don’t always agree on what’s hard, and constraining memory leads to some surprisingly clean theorems.

What We’re Measuring

Picture a Turing machine with a read-only input tape and separate work tapes, and count only the work tape cells it uses. That way a machine can read a huge input while remembering only a tiny summary, and “sublinear space” makes sense.

$\text{DSPACE}(s(n))$ is what a deterministic machine can decide using $O(s(n))$ work cells; $\text{NSPACE}$ is the nondeterministic version. Two classes matter most:

$$\mathbf{L} = \text{DSPACE}(\log n) \qquad \mathbf{PSPACE} = \bigcup_{k \geq 1} \text{DSPACE}(n^k)$$

Log space is tight: room for a few pointers into the input, never a copy of it. Polynomial space is generous: it contains all of P and NP, and probably more.

The Space Hierarchy Theorem

More space means strictly more power.

Theorem. If $s_1(n) = o(s_2(n))$ and $s_2(n) \geq \log n$, then $\text{DSPACE}(s_1(n)) \subsetneq \text{DSPACE}(s_2(n))$.

The proof is diagonalization : build a machine using $s_2(n)$ space that disagrees with every machine using less. So, for instance, $\text{SPACE}(n) \subsetneq \text{SPACE}(n^2)$. For space we can actually prove classes apart, which is more than we can do for P and NP.

PSPACE and Games

A computation running for $t$ steps can touch at most $t$ cells, so $\text{DTIME}(t) \subseteq \text{DSPACE}(t)$, and PSPACE contains P and NP. It may contain far more: problems that explore exponentially large spaces while reusing a polynomial amount of memory.

Its canonical complete problem is TQBF, true quantified Boolean formulas, where every variable is bound by alternating “there exists” and “for all”:

$$\exists x_1, \forall x_2, \exists x_3 \cdots\ \varphi(x_1, x_2, x_3, \ldots)$$

TQBF is to PSPACE what SAT is to NP. The alternation is a two-player game: one player picks the $\exists$ variables, the opponent the $\forall$ variables, and the formula is true when the first player can force a win. So PSPACE is the natural home of games: generalized Othello is PSPACE-complete, and generalized chess and Go reach the even harder EXPTIME-complete level.

Log Space: L and NL

$\mathbf{NL} = \text{NSPACE}(\log n)$ adds nondeterminism to log space. Its canonical complete problem is directed reachability: is there a path from $s$ to $t$? It’s in NL because you can guess the path one step at a time, remembering only the current vertex and a step counter, $O(\log n)$ bits. And everything in NL reduces to it: any log-space machine’s run is a walk through its graph of configurations.

Depth-first search, by contrast, keeps a stack that can grow to $O(n)$, so it isn’t a log-space algorithm. Yet undirected reachability is in L: Reingold proved in 2005 that it can be decided in $O(\log n)$ space, using a walk built from expander graphs with no stack at all.

Savitch’s Theorem

For time, we don’t know whether nondeterminism helps; that’s P vs NP. For space we know the answer: it helps at most quadratically.

Theorem (Savitch, 1970). For $s(n) \geq \log n$: $\ \text{NSPACE}(s(n)) \subseteq \text{DSPACE}(s(n)^2)$. In particular, NPSPACE = PSPACE.

The idea is to decide reachability between configurations by guessing a midpoint and halving: $C$ can reach $C'$ within $2^k$ steps exactly when some $C_m$ is reachable from $C$ within $2^{k-1}$ steps and can reach $C'$ within $2^{k-1}$. A deterministic machine just tries every possible $C_m$:

The time is enormous: every midpoint, at every level. But memory is reused: when one half finishes, its stack frame is erased and the next call writes over the same cells. The recursion is only $O(s(n))$ levels deep, since a machine with $O(s(n))$ space has $2^{O(s(n))}$ configurations, and each frame stores a configuration or two, $O(s(n))$ cells. Depth times frame size gives $O(s(n)^2)$.

NL = co-NL

Whether NP = co-NP is open. For NL, the answer is known.

Theorem (Immerman and Szelepcsényi, 1987). NL = co-NL.

So non-reachability, certifying that there’s no path from $s$ to $t$, is in NL too, even though it seems to require ruling out every possible path.

The trick is counting. A nondeterministic log-space machine can compute exactly how many vertices are reachable from $s$ within $i$ steps, using the count for $i - 1$ steps. Once it knows the true total $r$, it can find and verify $r$ distinct reachable vertices; if $t$ isn’t among them, $t$ is unreachable. Nondeterminism normally only guesses evidence that something exists. Counting turns it into a way to certify that something doesn’t.

“Does PSPACE tell us anything about P vs NP?" Not directly. We know $\mathbf{P} \subseteq \mathbf{NP} \subseteq \mathbf{PSPACE} \subseteq \mathbf{EXPTIME}$, and the time hierarchy theorem gives $\mathbf{P} \neq \mathbf{EXPTIME}$, so at least one of those inclusions is strict. Which one is unknown. It’s consistent with everything we know that P = NP = PSPACE, and also that all four classes differ.

Summary

Class Definition Representative problem Notes
$\mathbf{L}$ Deterministic log space Undirected reachability Reingold
$\mathbf{NL}$ Nondeterministic log space Directed reachability NL = co-NL; NL ⊆ P
$\mathbf{P}$ Deterministic polynomial time Sorting, shortest paths Whether P ⊆ NL is open
$\mathbf{NP}$ Nondeterministic polynomial time SAT, 3-coloring NP ⊆ PSPACE
$\mathbf{PSPACE}$ Polynomial space TQBF, games like Othello NPSPACE = PSPACE, by Savitch
$\mathbf{EXPSPACE}$ Exponential space Some formal-language problems PSPACE ⊊ EXPSPACE

The lessons: hierarchy theorems for space are clean, because space is reusable and diagonalization fits it perfectly. Nondeterminism costs at most a square for space, not an exponential. And even lopsided-looking questions like non-reachability become symmetric when memory is what’s scarce.
